# Model-family foundation status

This tracker is separate from the BitNet/hardware alignment tracker. It records model-family documentation, design scaffolds, receipt templates, and implementation lanes for future non-BitNet support.

## Current state

- Foundation docs: `design_scaffold` / `documented` only.
- Runtime behavior: not added.
- First local priorities: Qwen3.5 small models, Gemma 4 E2B/E4B text-only, and OpenAI privacy-filter token classification.
- Design-only families: Kimi K2.6, GLM-5.1, DeepSeek V4 Flash/Pro, and Mistral Medium 3.5 full path.

## Claim boundary

No file in this tracker claims that a model loads, runs, reaches long context, supports multimodal input, supports MoE routing, or achieves speedup unless a named receipt backs that exact model/variant/backend/task.
