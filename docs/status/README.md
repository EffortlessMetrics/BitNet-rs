# Maintenance Instruments

This directory stores high-signal maintenance artifacts generated by `scripts/generate_maintenance_artifacts.py` and `.github/workflows/maintenance-instruments.yml`.

## Artifacts

- `dependency-graph.mmd` / `dependency-graph.md`: workspace dependency topology as Mermaid.
- `public-api-summary.md`: deterministic hash + `pub` line summary for checked-in API snapshots in `docs/api/rust`.
- `churn.md`: 90-day hotspot report from git history.
- `invariants.md`: MSRV, contracts, and CI workflow inventory.
- `sbom.cyclonedx.json`: CycloneDX SBOM generated in CI and uploaded as workflow artifact.

## Generation

Run locally:

```bash
python3 scripts/generate_maintenance_artifacts.py
```

Run in CI:

- PR/push/schedule: `Maintenance Instruments` workflow.
- SBOM and policy gate: same workflow `sbom-and-policy` job.
