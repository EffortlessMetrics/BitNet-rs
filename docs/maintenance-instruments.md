# Repo Maintenance Instruments

This repository now ships a deterministic maintenance bundle generated by `scripts/maintenance/run_all.sh`.

## Generated artifacts

- `docs/deps.md` / `docs/deps.json`: workspace crate dependency graph.
- `docs/public_api/*.txt`: public API snapshots for selected contract crates.
- `docs/coverage.md`: fast coverage summary table.
- `docs/sbom.json`: CycloneDX SBOM.
- `docs/churn.md`: 90-day churn and hotspot report.
- `docs/status.md`: repo invariants status page (MSRV, CI gates, spec count).

## CI publication model

The `repo-instruments` workflow uses a low-noise pattern:

- **PRs:** generates artifacts and uploads them for review.
- **main/schedule/manual:** commits updated generated files with `[skip ci]`.

Dependency/license and perf guardrails remain in dedicated workflows (`security.yml`, `perf-gate.yml`).
