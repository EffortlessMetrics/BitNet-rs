================================================================================
                      NEXTEST PROFILE SUMMARY
================================================================================

All profiles in .config/nextest.toml:

  default:    Full test suite
              ├─ fail-fast: true
              ├─ test-threads: num-cpus
              └─ slow-timeout: 300s

  ci:         CI-specific (4 threads)
              ├─ fail-fast: false
              ├─ test-threads: 4 (FIXED)
              ├─ retries: 0
              └─ slow-timeout: 300s

  fixtures:   GGUF fixture tests (I/O bound)
              ├─ fail-fast: false
              ├─ test-threads: 2
              ├─ retries: 0
              └─ slow-timeout: 600s

  gpu:        GPU kernel tests
              ├─ fail-fast: false
              ├─ test-threads: 1 (GPU memory)
              ├─ retries: 0
              └─ slow-timeout: 300s

  doctests:   Documentation tests
              ├─ fail-fast: false
              ├─ test-threads: num-cpus
              ├─ retries: 0
              └─ slow-timeout: 120s

All profiles:
  - retries = 0 (no flaky test tolerance)
  - success-output = "never" (clean logs)
  - failure-output = "immediate"
