## Summary

Add a model format conversion pipeline for transforming SLM models between formats and dtypes.

## Components
- ConversionConfig: configurable source/target format, dtype, quantization
- ConversionPlan: step sequence with size and time estimates
- ConversionStep: LoadWeights, ConvertDtype, Quantize, PackTensors, ValidateOutput
- ModelFormat: SafeTensors, GGUF, ONNX, PyTorch
- DType: F32, F16, BF16, Int8, Int4 with bytes_per_element, is_quantized
- QuantizationSpec: Symmetric/Asymmetric with group_size and calibration

## Tests
33 tests covering format combinations, dtype properties, plan generation, size estimation.

## Validation
```bash
cargo test -p bitnet-models --no-default-features --features cpu -- conversion
cargo clippy -p bitnet-models --no-default-features --features cpu -- -D warnings
```
