# NPU productization plan

This plan governs BitNet-rs NPU productization as a docs/specs/status-first
campaign. The Intel Lunar Lake 258V Intel AI Boost NPU through OpenVINO NPU is
the first implementation target; Apple Neural Engine, Qualcomm Hexagon, and AMD
Ryzen AI remain separate future research families.

Start with [`implementation-plan.md`](implementation-plan.md) for the PR order,
proof commands, and claim boundaries.
